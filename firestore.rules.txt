Firestore 규칙 설정 (테스트 전용)

Firebase Console > Firestore Database > 규칙에서 아래를 적용하면 앱 연동을 테스트할 수 있습니다. 주의: 로그인 인증이 없는 상태라 URL을 아는 누구나 데이터를 읽고 쓰고 삭제할 수 있습니다. 실제 현장 데이터에 사용하지 말고, 테스트 후 인증 기능과 보안 규칙을 적용하세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tbmRecords/{recordId} { allow read, write: if true; }
    match /riskRecords/{recordId} { allow read, write: if true; }
  }
}
