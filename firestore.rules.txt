Firestore 규칙 설정

Firebase Console > Firestore Database > 규칙에 아래 규칙을 게시하세요. 익명 인증 사용자가 로그인된 경우에만 읽기/쓰기가 허용됩니다. 다만 공개 사이트의 익명 인증은 방문자 누구나 인증받을 수 있으므로 실제 운영 전에는 접근 제어를 더 강화하세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /tbmRecords/{recordId} { allow read, write: if request.auth != null; }
    match /riskRecords/{recordId} { allow read, write: if request.auth != null; }
  }
}
